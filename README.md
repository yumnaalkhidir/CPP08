# CPP08

42 School C++ Module 08 — templated containers, STL algorithms, and a custom iterator.

## Concepts covered
- STL algorithms applied to a generic container (easyfind)
- A templated Span class with STL-style insertion
- A custom MutantStack iterator adapter over std::stack

## Exercises
ex00 ex01 ex02 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
